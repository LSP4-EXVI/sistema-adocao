# Sistema de Controle de Animais para Adoção

## Objetivo

Criar um sistema simples para organizar informações de animais disponíveis para adoção.

## Funcionalidades planejadas

- Cadastrar animais.
- Listar animais cadastrados.
- Buscar animais pelo nome.
- Registrar adoções concluídas.

## Tecnologias

- Python
- Git
- GitHub
