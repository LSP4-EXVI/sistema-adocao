# Sistema de Controle de Animais para Adoção

## Objetivo

Criar um sistema simples para organizar informações de animais disponíveis para adoção.

## Funcionalidades implementadas

- Cadastrar animais
- Listar animais cadastrados
- Remover animais
- Editar informações dos animais
- Salvar e recuperar dados utilizando JSON

## Funcionalidades planejadas

- Buscar animais pelo nome
- Registrar adoções concluídas

## Tecnologias

- Python
- JSON
- Git
- GitHub

## Como executar o projeto 

Para executar o sistema, é necessário ter o Python instalado no computador.

1. **Obtenha os arquivos do projeto** 

    Clone o repositório utilizando o Git:

    ```bash
    git clone https://github.com/LSP4-EXVI/sistema-adocao.git
    ```

    Alternativamente, baixe os arquivos pelo GitHub utilizando a opção Code > Download ZIP.


2. **Acesse a pasta do projeto**

    Abra o terminal e navegue até a pasta do projeto:

    ```bash
    cd sistema-adocao   
    ```

3. **Execute o programa**

    No terminal, execute o seguinte comando:

    ```bash
    python main.py
    ```

    Após a execução, o menu principal do sistema será exibido no terminal.
